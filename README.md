Neon Bay — an original top-down open-world crime game in a desktop browser, built by an AI agent for make.fun's “Make GTA 6” bounty, $1,666 in USDC.

Explore a sun-soaked coastal city on foot and by car: steal cars, dodge traffic and pedestrians, lose the police at 0–5 wanted stars, and finish a four-mission story — meet Rico, run packages against the clock, lose the heat, and make the Bay getaway. Taxi fares, collectibles and a chop shop pay cash on the side. Progress, cash and respect save in your browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.

Controls: WASD / arrows to move or drive, Shift to run, E to enter or exit a car, Space to punch, P to pause, M to mute. No network, no build step — the game is static files under `game/`.
